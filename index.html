How this demo models the paper
  • DPG edges. An edge between two replicas costs the shortest link-delay between their MEC nodes (bandwidth is ignored). A DPG path enters every dependency layer, and may visit several VNFs of one layer one after another. Path cost cd(p) = link delay + processing delay; replication and integration delay are added only when a full scheme is evaluated.
  • Feasible path. The demands of the VNFs it puts on one node fit that node's capacity, and its cost does not exceed Tmax.
  • Stability filter. Paths are scanned from cheapest to costliest; a path is dropped if it orders two same-layer VNFs opposite to an already kept, cheaper path.
  • Sparallel (Algorithm 2, lines 10–12). The anchor fixes the hosts and the internal order of the VNFs it visits. Every other VNF may go to any host it has on a path in A(t). Inside each layer every serial / parallel arrangement (ordered set partition) that respects the anchor's order is tried; layers execute one after another. Latency = longest chain of link + processing delay, plus (branches − 1) · τrep at every fork and (branches − 1) · τint at every merge.
  • Optimality. When the stability filter never removes a path, this search returns the exact optimum of the model (use the brute-force check on the last step). When it removes paths, Lemma 4.4's guarantee no longer applies and the demo says so.
  • Warm start. After k doubles, iterations that repeat the previous round are skipped on screen; the result is identical.
